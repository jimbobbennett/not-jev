The API

Available endpoints

Every endpoint accepts POST and returns JSON.

POST/no

A decisive noul answer of 0. The answer is no.

curl -X POST https://not-jev.dev/no
POST/yes

A surprisingly decisive noul answer of 1. The answer is yes.

curl -X POST https://not-jev.dev/yes
POST/fuck-no

A noul answer of 0, with the appropriate level of emphasis.

curl -X POST https://not-jev.dev/fuck-no
POST/magic-8-ball

Uniformly chooses one of the classic 20 Magic 8 Ball responses.

curl -X POST https://not-jev.dev/magic-8-ball

Response format

Typed answers, tiny stakes

Responses follow the Jev-style model, answers, and usage envelope.

{
  "model": "not-jev",
  "answers": {
    "answer": {
      "type": "noul",
      "noul": 0
    }
  },
  "usage": {
    "input_tokens": 0,
    "output_tokens": 0
  },
  "response": "fuck no"
}

Noul responses use 0 for no and 1 for yes. The Magic 8 Ball endpoint returns a choice with a uniform probability for each classic response. Token usage is always zero.

Errors

Keep it simple

Unknown paths return 404. Methods other than POST return 405.
